# v1.2.0 — 完整思考过程、导入对话，以及一批修复

这一版把最近几轮的工作都收进来了：**完整思考过程**、**导入对话**，以及一个「给了本地路径却读不到」的关键修复。

## 本次新增

### 完整显示模型的思考过程

用推理模型（DeepSeek-R1、Claude 带 thinking、Gemini 2.5 等）时，思考过程会**逐字**显示在回答上方：

- **不截断、不摘要**：接口吐多少显示多少
- 默认展开，长思考内部可滚动；点「展开」解除限高，一次看完
- 标题实时显示字数（`💭 正在思考… 15,186 字`），可折叠成一行、可整段复制
- 写进对话存档，**刷新/重开软件后还在**；导出 Markdown 时放进 `<details>` 折叠块

之前三种协议各有各的毛病，这一版都修了：

| 协议 | 以前 | 现在 |
| --- | --- | --- |
| OpenAI 兼容 | 只认 `reasoning_content`，OpenRouter 用的 `reasoning` 收不到 | 三个字段名（`reasoning_content` / `reasoning` / `thinking`）都认 |
| Anthropic | 从不主动请求，所以永远没有思考返回 | 主动带 `thinking` 参数 |
| Gemini | `thought` 片段被**当成正文混进回答**，也没请求 `includeThoughts` | 思考单独归类，不再污染回答 |

**不会因为"想显示思考"把对话弄挂**：模型不认识思考参数时（如 Claude 3.5）接口会返回 400，
程序会自动去掉参数重试一次，只提示一句「本次没有思考过程」。

### 导入对话

侧栏「＋ 新建对话」旁边新增「⬆ 导入」：

- 导出的 **JSON**：完整还原，含全部消息版本
- 导出的 **Markdown**：按 `## 👤 用户` / `## 🤖 AI` 分段还原
- **整库备份**：里面每个对话各导入一份
- 其它 `.md` / `.txt`：整篇作为一条消息（认不出格式也不会失败）

**只追加、不覆盖**：现有对话一个都不动；导入的对话不绑定接口；导入前自动把当前数据另存一份。

## 本次修复

### 「给 AI 一个本地地址，它说读不到」

中文不写空格，所以 `读取D:\项目A里的内容` 才是最自然的写法 —— 而程序原来要求路径前后必须有空格或标点，
这种写法下**整条路径一个字符都认不出来**，于是什么都没读，AI 只能回一句「我读不到」。两个边界都修了：

- 路径**起点**：改成「前面只要是字母/数字/下划线就排除」——允许中文紧贴，同时仍然拦得住 `https://` 里的 `s:/`
- 路径**终点**：改成逐字符往短了试，自然落到 `D:\项目A`（原来只在分隔符处往回切，切到最后只剩 `D:\`）

顺带：**认出来但本机没有的路径，现在会明确提示**「⛔ 本机找不到这个路径，不会被读取」，
而不是默默忽略让你去猜。

### 其他

- `npm run build` 重建时**不会删用户数据**（原来会连 `dist\...\data` 里的接口配置一起删掉）
- `data.json` 带 BOM 或损坏时不再静默清空（会自动去 BOM；损坏则另存为 `.unreadable-<时间>` 并弹警告）
- 数据目录优先沿用「已经有数据」的那个，避免可访问性变化导致看起来像数据丢了
- 图标在小尺寸下改用 **BTC** 字母组合（三行文字缩到 16px 会糊成一团）

## 下载与安装

1. 下载下面的 `BetterThanChatbox-v1.2.0-win-x64.zip`，解压到任意目录（比如 `D:\BetterThanChatbox`）
2. 双击里面的 **`BetterThanChatbox.exe`**
3. 第一次打开会弹出「设置」→ 点「＋ 添加接口」：

| 填什么 | 例子 |
| --- | --- |
| 接口类型 | OpenAI 兼容 / Anthropic Claude / Google Gemini |
| Base URL | DeepSeek 填 `https://api.deepseek.com/v1`（Claude 和 Gemini 官方可留空） |
| API Key、模型名 | 例如 `sk-xxx`、`deepseek-chat` |

**从 v1.1.0 升级**：直接用新文件夹覆盖旧的 `app-runtime\` 和 `BetterThanChatbox.exe` 即可 ——
配置和对话存在 `%APPDATA%\BetterThanChatbox\`，不在程序目录里，不会被覆盖。

```
BetterThanChatbox\
  BetterThanChatbox.exe   ← 双击这个
  使用说明.txt
  app-runtime\            ← 程序本体（Electron 运行时 + 应用代码），别单独移动
```

- 下载 108 MB，解压后 265 MB（其中 255 MB 是 Electron 运行时本体，应用自己的代码只有 400 多 KB）
- 系统要求：Windows 10 / 11 64 位；免安装、不写注册表、不留后台常驻进程

## 功能一览

- **三种协议一套界面**：OpenAI 兼容（DeepSeek / OpenRouter / 硅基流动 / 中转站 / Ollama…）、Anthropic Claude、Google Gemini
- **模型下拉快捷切换**：列表来自接口、本机用过的模型、常用模型三组，可搜索、可自己输
- **读本地文档**：消息里写文件夹路径（`读取D:\项目A里的内容`）→ 应用把里面的文档读出来一起发给 AI
- **一键存回本地**：AI 回答下面点「💾 保存到 项目A/」，总结直接落进那个文件夹
- **发图发文件**：图片按视觉消息发；Word / Excel / PPT / PDF 自动提取正文
- **导入 / 导出**：对话可导出成 Markdown / JSON，也能导回来；设置里可整库备份与恢复
- **流式输出**、Markdown + 代码高亮、重新回答 / 编辑提问开分支
- **浅色米白 / 深色深绿**两套主题，可跟随系统

## 数据存在哪

`%APPDATA%\BetterThanChatbox\` —— `data.json`（接口配置含 API Key、对话、消息）+ `files\`（附件原文件）。
设置面板里「打开数据目录」可以直接打开。把整个文件夹拷走就是完整备份。

## 关于 Windows 的拦截提示

exe **没有代码签名**（个人开源项目通常都不做），所以：

- 第一次运行可能弹 **「Windows 已保护你的电脑」** → 点「更多信息」→「仍要运行」
- 更省事：**先右键压缩包 → 属性 → 勾选「解除锁定」→ 再解压**，之后就不会弹

## 已知限制

- 老格式 `.doc` / `.xls` / `.ppt`（二进制 OLE）只发送文件名，不读正文
- 扫描件 / 图片型 PDF 提不出文字（会提示）
- 文件夹里的图片只列名字，不发正文（需要的话单独拖进来）
- 单个附件上限 30 MB；文件夹单次最多读 40 个文件、3 层目录、正文 20 万字符
- API Key 以明文存在本机 `data.json` 里，别把这个文件发给别人
