# v1.1.0 — 可以让 AI 读本地文件夹了

在 v1.0.0 的基础上加了一个大功能：**读本地文档 / 文件夹，并把回答一键存回本地**。

## 本次新增

### 读本地文件夹

在消息里直接写上文件夹路径，应用会把里面的文档读出来一起发给 AI：

```
帮我总结一下 D:\项目A 这个文件夹里的内容
```

发送前输入框上方会出现一条提示，**让你看清会读什么**：

```
📁 项目A/ · 12 个可读文件 · 340 KB · 发送时读取内容        [✕]
```

点 ✕ 可以这次不读它。读到的正文里带每个文件的分节标题，还会附一份「哪些文件没读、为什么没读」的清单
（比如 `data.bin（2.1 MB）文件过大`、`logo.png 图片（不读正文）`）。

单个文件路径也行：`D:\报告.docx` 直接当附件发。

支持的格式：`txt / md / json / csv / 各种代码文件`、`docx / xlsx / pptx`、`pdf`。
（老格式 `.doc / .xls / .ppt` 不支持，只发文件名。）

### 把回答一键存回本地

AI 回答下面会多一个按钮：

```
💾 保存到 项目A/        ← 带了文件夹路径时，默认就存回那个文件夹
💾 保存为文件           ← 没带路径时，自己选地方
```

文件名默认取回答里的第一个标题 + 日期，重名会先问你要不要覆盖。

### 一些边界

| 限制 | 值 |
| --- | --- |
| 单次最多读 | 40 个文件 |
| 目录深度 | 3 层 |
| 单个文件 | 5 MB |
| 正文总量 | 20 万字符 |
| 自动跳过 | `node_modules`、`.git`、`__pycache__`、`.venv`、隐藏目录 |
| 直接拒绝 | 盘符根目录（`C:\`、`D:\`）、`C:\Windows`、`Program Files`、`ProgramData` |

**为什么是应用去读、而不是给 AI 工具权限**：文档正文里可能藏着"顺便读一下 `~/.ssh`"这类注入指令，
给模型工具权限它就真会去读；现在是应用认路径、应用去读，模型只拿到你点过头的那份内容。
另外这样不依赖模型支持 function calling —— DeepSeek、中转站、本地 Ollama 上的小模型都能用。

对话记录里**只存路径和文件清单，不存正文**：真正的内容在发请求那一刻现读。所以读过一个大文件夹
不会让 `data.json` 膨胀，内容也永远是最新的。

## 下载与安装

1. 下载下面的 `BetterThanChatbox-v1.1.0-win-x64.zip`，解压到任意目录（比如 `D:\BetterThanChatbox`）
2. 双击里面的 **`BetterThanChatbox.exe`**
3. 第一次打开会弹出「设置」→ 点「＋ 添加接口」，填三样东西：

| 填什么 | 例子 |
| --- | --- |
| 接口类型 | OpenAI 兼容 / Anthropic Claude / Google Gemini |
| Base URL | DeepSeek 填 `https://api.deepseek.com/v1`（Claude 和 Gemini 官方可留空） |
| API Key、模型名 | 例如 `sk-xxx`、`deepseek-chat` |

点「保存」和「设为当前」，回到主界面就能聊了。

```
BetterThanChatbox\
  BetterThanChatbox.exe   ← 双击这个
  使用说明.txt
  app-runtime\            ← 程序本体（Electron 运行时 + 应用代码），别单独移动
```

- 下载 108 MB，解压后 265 MB（其中 255 MB 是 Electron 运行时本体，应用自己的代码只有 400 多 KB）
- 系统要求：Windows 10 / 11 64 位
- 免安装：不写注册表、不装服务、不留后台常驻进程；卸载就是删掉文件夹

## 其他功能（v1.0.0 就有）

- **三种协议一套界面**：顶栏下拉随时切；支持存多个接口配置
- **模型下拉快捷切换**：列表来自接口、本机用过的模型、常用模型三组，可搜索、也可自己输模型名
- **发图发文件**：图片按视觉消息发；Word / Excel / PPT / PDF 自动提取正文
- **流式输出**、Markdown + 代码高亮、重新回答 / 编辑提问开分支
- **对话管理**：新建、删除、重命名，导出成 Markdown / JSON
- **备份与恢复**：设置里一键导出全部数据（含接口配置），换机器时导入即可
- **浅色米白 / 深色深绿**两套主题，可跟随系统

## 数据存在哪

`%APPDATA%\BetterThanChatbox\` —— `data.json`（接口配置含 API Key、对话、消息）+ `files\`（附件原文件）。
设置面板里「打开数据目录」可以直接打开。把整个文件夹拷走就是完整备份。

## 关于 Windows 的拦截提示

这个 exe **没有做代码签名**（个人开源项目通常都不做，证书要花钱），所以：

- 下载的压缩包会被 Windows 标记「来自 Internet」，第一次运行可能弹 **「Windows 已保护你的电脑」** → 点「更多信息」→「仍要运行」
- 更省事的做法：**先右键压缩包 → 属性 → 勾选「解除锁定」→ 再解压**，之后就不会弹了
- 公司电脑有应用白名单的可能直接被拦，那种情况只能自己 `npm run build` 从源码打包

## 已知限制

- 老格式 `.doc` / `.xls` / `.ppt`（二进制 OLE）只发送文件名，不读正文
- 扫描件 / 图片型 PDF 提不出文字（会提示）
- 文件夹里的图片只列名字，不发正文（几十张图全发出去太贵，需要的话单独拖进来）
- 单个附件上限 30 MB
- API Key 以明文存在本机 `data.json` 里，别把这个文件发给别人
